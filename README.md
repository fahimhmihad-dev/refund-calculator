# Refund Calculator — Prorated Refund Tool

A web tool that calculates a prorated refund from the amount paid, purchase date, refund date, and package duration.

🔗 **Live Website:** https://refund.getyourservicebd.store/
🔗 **Also deployed at:** https://refund-gys.lovable.app

## About the Project
A practical utility built for a real business need: working out exactly how much refund a customer should receive for the unused part of a package.

## Features
- Input amount paid (৳), purchase & refund dates, package duration
- Calculates prorated refund for the unused period
- Simple, purpose-built interface

## Tech Stack

- HTML5, CSS3
- Built with AI-assisted development tools (Lovable / Antigravity workflow)
- Deployed live on a custom domain

## What I Learned
- Turning a real business calculation into a web tool
- Date and duration based calculation logic
